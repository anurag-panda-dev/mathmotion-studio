# Branding

Source assets, exports, and usage rules for the MathMotion Studio identity.

> **Status:** Complete for the documentation phase (see [`assets-manifest.md`](assets-manifest.md) for provenance and open deliverables). The application UI that will consume these assets is not yet implemented ([`docs/ROADMAP.md`](../docs/ROADMAP.md)).

## Contents

| File | What it is |
|---|---|
| [`BRAND_GUIDELINES.md`](BRAND_GUIDELINES.md) | Full guidelines: variants, colors (measured), typography, clear space, do/don't, accessibility, export naming. |
| [`palette.json`](palette.json) | Machine-readable palette — brand colors measured from the rasters + scene-format colors + WCAG ratios. |
| [`assets-manifest.md`](assets-manifest.md) | Provenance of every asset, verification performed, and what is explicitly missing. |
| [`logo-primary.svg`](logo-primary.svg) | Canonical horizontal lockup — **for light backgrounds**. |
| [`logo-dark.svg`](logo-dark.svg) | Horizontal lockup for dark/navy backgrounds. |
| [`logo-symbol.svg`](logo-symbol.svg) | The mark alone (orbits + trajectory), light-context colors. |
| [`logo-monochrome.svg`](logo-monochrome.svg) | One-color lockup, inherits `currentColor`. |
| [`app-icon.svg`](app-icon.svg) / [`app-icon.png`](app-icon.png) / [`app-icon.ico`](app-icon.ico) | Application icon: vector + 256² PNG + multi-size ICO (16–256). |
| [`favicon.svg`](favicon.svg) | Simplified bold-stroke mark for browser tabs. |

There is deliberately **no `logo-light.svg`**: `logo-primary.svg` *is* the light variant — one source of truth (rationale in the guidelines §2).

## Canonical colors

| | Hex | |
|---|---|---|
| Navy | `#061830` | ink / dark surface |
| Violet | `#6A4AEE` | accent / trajectory |
| Ivory | `#F1F3EA` | light ink |

Measured from `assets/*.png` by pixel sampling — observed ranges and contrast ratios are in [`palette.json`](palette.json).

## Quick use

```html
<!-- light surface -->
<img src="branding/logo-primary.svg" alt="MathMotion Studio">
<!-- dark surface (pair with the navy background) -->
<img src="branding/logo-dark.svg" alt="MathMotion Studio">
```

```powershell
# regenerate the derived icon exports from the original raster (requires Pillow)
python -c "from PIL import Image; src=Image.open('assets/mathmotion_app_icon.png').convert('RGB'); w,h=src.size; s=max(w,h); c=Image.new('RGB',(s,s),(6,24,48)); c.paste(src,((s-w)//2,(s-h)//2)); c.resize((256,256),Image.LANCZOS).save('branding/app-icon.png')"
```

Before using any asset, read the **do/don't** list and clear-space rules in [`BRAND_GUIDELINES.md`](BRAND_GUIDELINES.md). The SVG files are generated by `tools\build_brand_svgs.py` from the potrace outlines and raster masters — regenerate with `python tools\build_brand_svgs.py` rather than editing them by hand. Provenance and the missing deliverables are listed in [`assets-manifest.md`](assets-manifest.md).
